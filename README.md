# UrbanNest Interiors & Architecture

A contemporary interior design studio website featuring editorial minimalism, natural material palettes, and an AI-powered design assistant.

## Overview

UrbanNest is a modern interior design website concept based in Hyderabad, India. It showcases residential and commercial interior solutions through a refined visual identity, intuitive layouts, and an AI-powered design assistant that helps users explore interior design ideas.

The project combines responsive web design with AI integration to create an engaging digital experience for homeowners and design enthusiasts.

## Features

- **AI Design Assistant (NestAI):** An interactive AI-powered assistant that provides interior design suggestions and helps users explore design possibilities.
- **Residential & Commercial Interiors:** Dedicated sections showcasing interior solutions for homes, modular kitchens, offices, and custom spaces.
- **Material & Color Inspiration:** Design-focused content featuring natural wood, marble, linen, and complementary color palettes.
- **Interactive Design System:** CSS custom properties for managing visual styles and supporting dynamic theme customization.
- **Interior Design Packages:** Informational pricing sections for modular kitchens, residential interiors, and commercial spaces.

## Tech Stack

- **Structure:** HTML5
- **Styling:** CSS3, CSS Grid, Flexbox, CSS Custom Properties
- **Interactivity:** Vanilla JavaScript
- **AI Integration:** External AI API
- **Typography:** Playfair Display and Inter

## Getting Started

1. Clone or download the repository.
2. Open the project folder in your preferred code editor.
3. Launch `index.html` in a browser or use the VS Code Live Server extension.
4. Explore the website and interact with the available features.

If your AI integration requires environment variables or a backend service, configure those according to your implementation before running the application.
